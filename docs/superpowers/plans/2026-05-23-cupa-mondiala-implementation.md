# Cupa Mondiala Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a World Cup 2026 predictions web app for a private friend group, with invite-code registration, match/standings/bonus predictions, automatic + manual result sync, and a live leaderboard. Romanian UI, mobile-first.

**Architecture:** Next.js App Router (full-stack). PostgreSQL via Prisma. NextAuth v5 Credentials provider with DB sessions. Server components for reads, API routes for mutations. Railway cron triggers a results-sync endpoint that calls football-data.org; admin panel is the manual fallback. Scoring is a pure-function library called by both auto-sync and manual entry paths.

**Tech Stack:** Next.js 15+ (App Router), React 19, TypeScript, Tailwind CSS, Prisma, PostgreSQL, NextAuth v5 (Auth.js), bcryptjs, Jest + React Testing Library, deployed on Railway.

```ts
export type MatchScore = { ph: number; pa: number };
export type MatchResult = { ah: number; aa: number };

export type KnockoutPrediction = {
  ph: number;
  pa: number;
  predictsEt: boolean;
  predictsPens: boolean;
};

export type KnockoutResult = {
  ah: number;
  aa: number;
  wentToEt: boolean;
  wentToPens: boolean;
};

function sign(n: number): -1 | 0 | 1 {
  return n > 0 ? 1 : n < 0 ? -1 : 0;
}

export function groupMatchPoints(pred: MatchScore, actual: MatchResult): number {
  const predictedResult = sign(pred.ph - pred.pa);
  const actualResult = sign(actual.ah - actual.aa);

  if (predictedResult !== actualResult) return 0;
  if (pred.ph === actual.ah && pred.pa === actual.aa) return 7;
  if (pred.ph === actual.ah || pred.pa === actual.aa) return 5;
  return 2;
}

export function knockoutMatchPoints(
  pred: KnockoutPrediction,
  actual: KnockoutResult
): number {
  const predictedResult = sign(pred.ph - pred.pa);
  const actualResult = sign(actual.ah - actual.aa);

  if (predictedResult !== actualResult) return 0;

  const exactScore = pred.ph === actual.ah && pred.pa === actual.aa;
  if (!exactScore) return 4;

  const etPensMatch =
    pred.predictsEt === actual.wentToEt && pred.predictsPens === actual.wentToPens;
  if (etPensMatch) return 10;
  return 8;
}

export function groupStandingPoints(
  predicted: Record<number, number>,
  actual: Record<number, number>
): number {
  let pts = 0;
  for (const position of [1, 2, 3, 4]) {
    if (predicted[position] === actual[position]) pts += 3;
  }
  return pts;
}

export type DarkHorseRound =
  | "GROUP_EXIT"
  | "R32"
  | "R16"
  | "QF"
  | "SF"
  | "FINAL"
  | "WINNER";

const DARK_HORSE_POINTS: Record<DarkHorseRound, number> = {
  GROUP_EXIT: 0,
  R32: 3,
  R16: 6,
  QF: 10,
  SF: 15,
  FINAL: 22,
  WINNER: 30,
};

export function darkHorsePoints(round: DarkHorseRound): number {
  return DARK_HORSE_POINTS[round];
}

export const BONUS_POINTS = {
  champion: 20,
  runnerUp: 10,
  topScorer: 15,
};
```

```ts
const LOCK_OFFSET_MS = 60 * 60 * 1000; // 1 hour before kickoff

export function lockTimeFor(kickoff: Date): Date {
  return new Date(kickoff.getTime() - LOCK_OFFSET_MS);
}

export function isMatchLocked(kickoff: Date, now: Date = new Date()): boolean {
  return now.getTime() >= lockTimeFor(kickoff).getTime();
}

export async function tournamentLockTime(prisma: { match: { findFirst: (args: unknown) => Promise<{ kickoffTime: Date } | null> } }): Promise<Date | null> {
  const first = await prisma.match.findFirst({
    orderBy: { kickoffTime: "asc" },
    select: { kickoffTime: true },
  });
  return first?.kickoffTime ?? null;
}

export function isTournamentLocked(tournamentStart: Date | null, now: Date = new Date()): boolean {
```

```ts
import { TEAMS } from "./data/teams";
import { GROUP_FIXTURE_TEMPLATE, MATCHDAY_DATES, KNOCKOUT_SLOTS } from "./data/fixtures";

const prisma = new PrismaClient();

async function main() {
  // 1. Groups A–L
  const groupNames = ["A", "B", "C", "D", "E", "F", "G", "H", "I", "J", "K", "L"];
  for (const name of groupNames) {
    await prisma.group.upsert({
      where: { name },
      update: {},
      create: { name },
    });
  }

  // 2. Teams
  const groupMap = new Map<string, number>();
  for (const g of await prisma.group.findMany()) groupMap.set(g.name, g.id);

  for (const t of TEAMS) {
    await prisma.team.upsert({
      where: { fifaCode: t.fifaCode } as any,
      update: {},
      create: {
        name: t.name,
        fifaCode: t.fifaCode,
        flagEmoji: t.flagEmoji,
        pot: t.pot,
        groupId: groupMap.get(t.group)!,
      },
    });
  }

  // Note: fifaCode isn't @unique in the schema as-is for upsert. If you want safe
  // re-seeding, add @unique to fifaCode in schema.prisma and re-run migrate.
  // For now, delete-and-recreate is also acceptable for early dev:
  //   await prisma.team.deleteMany();

  // 3. Group-stage matches
  for (const groupName of groupNames) {
    const teamsInGroup = await prisma.team.findMany({
      where: { groupId: groupMap.get(groupName) },
      orderBy: { pot: "asc" },
    });
    const teamByPot = new Map(teamsInGroup.map((t) => [t.pot, t.id]));

    for (const fixture of GROUP_FIXTURE_TEMPLATE) {
      const homeId = teamByPot.get(fixture.homePot)!;
      const awayId = teamByPot.get(fixture.awayPot)!;
      await prisma.match.create({
        data: {
          homeTeamId: homeId,
          awayTeamId: awayId,
          groupId: groupMap.get(groupName)!,
          round: fixture.round as Round,
          kickoffTime: new Date(MATCHDAY_DATES[fixture.round]),
          status: "SCHEDULED",
        },
      });
    }
  }

  // 4. Knockout slot placeholders
  for (const slot of KNOCKOUT_SLOTS) {
    await prisma.match.create({
      data: {
        round: slot.round as Round,
        kickoffTime: new Date(slot.kickoffTime),
        slotDescription: slot.slotDescription,
        status: "SCHEDULED",
        // homeTeamId and awayTeamId are null until bracket resolves
      },
    });
  }

  // 5. Initial invite code
  const code = process.env.SEED_INVITE_CODE ?? "cupa2026";
  await prisma.inviteCode.upsert({
    where: { code },
    update: { isActive: true },
    create: { code, isActive: true },

  console.log("✅ Seed complete");
}

  .catch((e) => {
    console.error(e);
    process.exit(1);
  })
  .finally(async () => {
    await prisma.$disconnect();
  });
```

```ts
import Credentials from "next-auth/providers/credentials";
import bcrypt from "bcryptjs";
import { prisma } from "@/lib/prisma";
import { authConfig } from "./auth.config";

export const { handlers, signIn, signOut, auth } = NextAuth({
  ...authConfig,

    Credentials({
```

```ts
import { NextResponse } from "next/server";
import bcrypt from "bcryptjs";
import { z } from "zod";
import { prisma } from "@/lib/prisma";

const schema = z.object({
  inviteCode: z.string().min(1, "Cod de invitație necesar"),
  username: z
    .string()
    .min(3, "Minim 3 caractere")
    .max(30)
    .regex(/^[a-zA-Z0-9_-]+$/, "Doar litere, cifre, _ și -"),
  password: z.string().min(8, "Minim 8 caractere"),
});

export async function POST(req: Request) {
  const body = await req.json().catch(() => null);
  const parsed = schema.safeParse(body);
  if (!parsed.success) {
    return NextResponse.json(
      { error: parsed.error.issues[0].message },
      { status: 400 }
    );
  }

  const { inviteCode, username, password } = parsed.data;

  const code = await prisma.inviteCode.findUnique({ where: { code: inviteCode } });
  if (!code || !code.isActive) {
    return NextResponse.json({ error: "Cod de invitație invalid" }, { status: 403 });
  }

  const existing = await prisma.user.findUnique({ where: { username } });
  if (existing) {
    return NextResponse.json({ error: "Numele de utilizator e deja luat" }, { status: 409 });
  }

  const passwordHash = await bcrypt.hash(password, 10);
  await prisma.user.create({
    data: { username, passwordHash, isAdmin: false },
  });

  return NextResponse.json({ ok: true });
}
```

```ts
import { NextResponse } from "next/server";
import { z } from "zod";
import { auth } from "@/auth";
import { prisma } from "@/lib/prisma";
import { isMatchLocked } from "@/lib/locking";

const schema = z.object({
  matchId: z.number().int(),
  homeScore: z.number().int().min(0).max(20),
  awayScore: z.number().int().min(0).max(20),
  predictsEt: z.boolean().optional(),
  predictsPens: z.boolean().optional(),
});

export async function POST(req: Request) {
  const session = await auth();
  if (!session?.user?.id) return NextResponse.json({ error: "Unauthorized" }, { status: 401 });

  const body = await req.json().catch(() => null);
  const parsed = schema.safeParse(body);
  if (!parsed.success) {
    return NextResponse.json({ error: parsed.error.issues[0].message }, { status: 400 });
  }

  const match = await prisma.match.findUnique({ where: { id: parsed.data.matchId } });
  if (!match) return NextResponse.json({ error: "Meci inexistent" }, { status: 404 });

  if (isMatchLocked(match.kickoffTime)) {
    return NextResponse.json({ error: "Pronosticul e blocat" }, { status: 403 });
  }

  // Group stage matches must not have predictsEt/predictsPens set
  const isKnockout = !["GROUP_1", "GROUP_2", "GROUP_3"].includes(match.round);

  await prisma.matchPrediction.upsert({
    where: {
      userId_matchId: { userId: session.user.id, matchId: parsed.data.matchId },
    },
    update: {
      homeScore: parsed.data.homeScore,
      awayScore: parsed.data.awayScore,
      predictsEt: isKnockout ? (parsed.data.predictsEt ?? false) : null,
      predictsPens: isKnockout ? (parsed.data.predictsPens ?? false) : null,
    },
    create: {
      userId: session.user.id,
      matchId: parsed.data.matchId,
      homeScore: parsed.data.homeScore,
      awayScore: parsed.data.awayScore,
      predictsEt: isKnockout ? (parsed.data.predictsEt ?? false) : null,
      predictsPens: isKnockout ? (parsed.data.predictsPens ?? false) : null,
    },
  });

  return NextResponse.json({ ok: true });
}
```

```tsx
"use client";

import { useEffect, useState } from "react";
import { lockTimeFor, isMatchLocked } from "@/lib/locking";

export function CountdownLock({ kickoff }: { kickoff: Date }) {
  const [tick, setTick] = useState(0);

  useEffect(() => {
    const interval = setInterval(() => setTick((t) => t + 1), 60_000);
    return () => clearInterval(interval);
  }, []);

  const now = new Date();
  if (isMatchLocked(kickoff, now)) {
    return <span className="text-red-400 text-xs">🔒 Blocat</span>;
  }

  const lockAt = lockTimeFor(kickoff);
  const diffMs = lockAt.getTime() - now.getTime();
  const hours = Math.floor(diffMs / (60 * 60 * 1000));
  const minutes = Math.floor((diffMs % (60 * 60 * 1000)) / (60 * 1000));

  return (
    <span className="text-amber-400 text-xs" key={tick}>
      Blocare în {hours}h {minutes}m
    </span>
  );
}
```

```ts
import { NextResponse } from "next/server";
import { z } from "zod";
import { auth } from "@/auth";
import { prisma } from "@/lib/prisma";
import { isTournamentLocked, tournamentLockTime } from "@/lib/locking";

const schema = z.object({
  groupId: z.number().int(),
  standings: z
    .array(z.object({ position: z.number().int().min(1).max(4), teamId: z.number().int() }))
    .length(4),
});

export async function POST(req: Request) {
  const session = await auth();
  if (!session?.user?.id) return NextResponse.json({ error: "Unauthorized" }, { status: 401 });

  const body = await req.json().catch(() => null);
  const parsed = schema.safeParse(body);
  if (!parsed.success) {
    return NextResponse.json({ error: parsed.error.issues[0].message }, { status: 400 });
  }

  const lockAt = await tournamentLockTime(prisma);
  if (isTournamentLocked(lockAt)) {
    return NextResponse.json({ error: "Pronosticurile sunt blocate" }, { status: 403 });
  }

  // Validate: all 4 teams must belong to the group, no duplicates
  const teamsInGroup = await prisma.team.findMany({ where: { groupId: parsed.data.groupId } });
  const validIds = new Set(teamsInGroup.map((t) => t.id));
  const givenIds = parsed.data.standings.map((s) => s.teamId);
  const allValid = givenIds.every((id) => validIds.has(id));
  const uniqueCount = new Set(givenIds).size;

  if (!allValid || uniqueCount !== 4) {
    return NextResponse.json(
      { error: "Selecție invalidă — alege fiecare echipă o singură dată" },
      { status: 400 }
    );
  }

  // Upsert all 4 positions in a transaction
  await prisma.$transaction(
    parsed.data.standings.map((s) =>
      prisma.groupStandingPrediction.upsert({
        where: {
          userId_groupId_position: {
            userId: session.user.id,
            groupId: parsed.data.groupId,
            position: s.position,
          },
        },
        update: { teamId: s.teamId },
        create: {
          userId: session.user.id,
          groupId: parsed.data.groupId,
          position: s.position,
          teamId: s.teamId,
        },
      })
    )
  );

  return NextResponse.json({ ok: true });
}
```

```ts
import { NextResponse } from "next/server";
import { z } from "zod";
import { auth } from "@/auth";
import { prisma } from "@/lib/prisma";
import { isTournamentLocked, tournamentLockTime } from "@/lib/locking";

const schema = z.object({
  championTeamId: z.number().int(),
  runnerUpTeamId: z.number().int(),
  topScorerName: z.string().min(2).max(100),
  darkHorseTeamId: z.number().int(),
});

export async function POST(req: Request) {
  const session = await auth();
  if (!session?.user?.id) return NextResponse.json({ error: "Unauthorized" }, { status: 401 });

  const body = await req.json().catch(() => null);
  const parsed = schema.safeParse(body);
  if (!parsed.success) {
    return NextResponse.json({ error: parsed.error.issues[0].message }, { status: 400 });
  }

  const lockAt = await tournamentLockTime(prisma);
  if (isTournamentLocked(lockAt)) {
    return NextResponse.json({ error: "Pronosticurile sunt blocate" }, { status: 403 });
  }

  if (parsed.data.championTeamId === parsed.data.runnerUpTeamId) {
    return NextResponse.json({ error: "Campionul și finalista trebuie să fie diferite" }, { status: 400 });
  }

  const darkHorse = await prisma.team.findUnique({ where: { id: parsed.data.darkHorseTeamId } });
  if (!darkHorse || (darkHorse.pot !== 3 && darkHorse.pot !== 4)) {
    return NextResponse.json(
      { error: "Cal negru trebuie să fie din urna 3 sau 4" },
      { status: 400 }
    );
  }

  await prisma.bonusPrediction.upsert({
    where: { userId: session.user.id },
    update: parsed.data,
    create: { userId: session.user.id, ...parsed.data },
  });

  return NextResponse.json({ ok: true });
}
```

```ts
import { Prisma, PrismaClient, Round, MatchStatus } from "@prisma/client";
import { groupMatchPoints, knockoutMatchPoints, groupStandingPoints, darkHorsePoints, DarkHorseRound } from "@/lib/scoring";

const GROUP_ROUNDS: Round[] = ["GROUP_1", "GROUP_2", "GROUP_3"];

export function computePointsForPrediction(
  match: { round: Round; homeScore: number; awayScore: number; wentToEt: boolean | null; wentToPens: boolean | null },
  pred: { homeScore: number; awayScore: number; predictsEt: boolean | null; predictsPens: boolean | null }
): number {
  if (GROUP_ROUNDS.includes(match.round)) {
    return groupMatchPoints(
      { ph: pred.homeScore, pa: pred.awayScore },
      { ah: match.homeScore, aa: match.awayScore }
    );
  }
  return knockoutMatchPoints(
    {
      ph: pred.homeScore,
      pa: pred.awayScore,
      predictsEt: pred.predictsEt ?? false,
      predictsPens: pred.predictsPens ?? false,
    },
    {
      ah: match.homeScore,
      aa: match.awayScore,
      wentToEt: match.wentToEt ?? false,
      wentToPens: match.wentToPens ?? false,
    }
  );
}

export async function recalcPointsForMatch(
  prisma: PrismaClient,
  matchId: number
): Promise<void> {
  const match = await prisma.match.findUnique({ where: { id: matchId } });
  if (!match || match.homeScore === null || match.awayScore === null) return;

  const preds = await prisma.matchPrediction.findMany({ where: { matchId } });

  await prisma.$transaction(
    preds.map((p) =>
      prisma.matchPrediction.update({
        where: { id: p.id },
        data: {
          pointsAwarded: computePointsForPrediction(
            { round: match.round, homeScore: match.homeScore!, awayScore: match.awayScore!, wentToEt: match.wentToEt, wentToPens: match.wentToPens },
            { homeScore: p.homeScore, awayScore: p.awayScore, predictsEt: p.predictsEt, predictsPens: p.predictsPens }
          ),
        },
      })
    )
  );
}

// Final group standings: derived from completed match results.
// Tiebreakers (simplified): points → goal difference → goals scored → head-to-head.
// For an admin app, derive from match results; if ties remain, admin can manually adjust.
export async function recalcGroupStandings(prisma: PrismaClient, groupId: number): Promise<void> {
  const matches = await prisma.match.findMany({
    where: { groupId, round: { in: GROUP_ROUNDS } },
    include: { homeTeam: true, awayTeam: true },
  });

  // Bail if not all group matches are finished
  if (matches.some((m) => m.status !== MatchStatus.FINISHED || m.homeScore === null)) return;

  const teams = await prisma.team.findMany({ where: { groupId } });
  const stats = new Map<number, { pts: number; gf: number; ga: number; gd: number }>();
  for (const t of teams) stats.set(t.id, { pts: 0, gf: 0, ga: 0, gd: 0 });

  for (const m of matches) {
    const h = stats.get(m.homeTeamId!)!;
    const a = stats.get(m.awayTeamId!)!;
    h.gf += m.homeScore!;
    h.ga += m.awayScore!;
    a.gf += m.awayScore!;
    a.ga += m.homeScore!;
    if (m.homeScore! > m.awayScore!) h.pts += 3;
    else if (m.homeScore! < m.awayScore!) a.pts += 3;
    else { h.pts += 1; a.pts += 1; }
  }
  for (const s of stats.values()) s.gd = s.gf - s.ga;

  // Sort teams: pts desc, gd desc, gf desc, id asc (stable)
  const sortedTeamIds = [...stats.entries()]
    .sort(([, A], [, B]) => B.pts - A.pts || B.gd - A.gd || B.gf - A.gf)
    .map(([teamId]) => teamId);

  const actualByPosition: Record<number, number> = {
    1: sortedTeamIds[0],
    2: sortedTeamIds[1],
    3: sortedTeamIds[2],
    4: sortedTeamIds[3],
  };

  // Score every user's prediction for this group
  const preds = await prisma.groupStandingPrediction.findMany({ where: { groupId } });
  const byUser = new Map<number, Record<number, number>>();
  for (const p of preds) {
    if (!byUser.has(p.userId)) byUser.set(p.userId, {});
    byUser.get(p.userId)![p.position] = p.teamId;
  }

  await prisma.$transaction(
    [...byUser.entries()].flatMap(([userId, predicted]) => {
      const totalPts = groupStandingPoints(predicted, actualByPosition);
      // Award 3pts per correct position by checking each
      return [1, 2, 3, 4].map((pos) =>
        prisma.groupStandingPrediction.updateMany({
          where: { userId, groupId, position: pos },
          data: { pointsAwarded: predicted[pos] === actualByPosition[pos] ? 3 : 0 },
        })
      );
    })
  );
}

// Dark horse: triggered after each KO round completes
export async function recalcDarkHorse(prisma: PrismaClient): Promise<void> {
  const allKo = await prisma.match.findMany({
    where: { round: { in: ["R32", "R16", "QF", "SF", "FINAL"] } },
  });
  const finishedTeamIds = new Set<number>();
  const advancedByRound: Record<string, Set<number>> = {
    R32: new Set(), R16: new Set(), QF: new Set(), SF: new Set(), FINAL: new Set(),
  };
  let championId: number | null = null;

  for (const m of allKo) {
    if (m.status !== MatchStatus.FINISHED) continue;
    if (m.homeTeamId) finishedTeamIds.add(m.homeTeamId);
    if (m.awayTeamId) finishedTeamIds.add(m.awayTeamId);

    const winnerId =
      m.wentToPens
        ? (m.homeScore! > m.awayScore! ? m.homeTeamId : m.awayTeamId) // 90-min score encodes pen winner per our convention
        : m.homeScore! > m.awayScore! ? m.homeTeamId : m.awayScore! > m.homeScore! ? m.awayTeamId : null;

    if (!winnerId) continue;
    advancedByRound[m.round]?.add(winnerId);
    if (m.round === "FINAL") championId = winnerId;
  }

  const bonusPreds = await prisma.bonusPrediction.findMany();

  await prisma.$transaction(
    bonusPreds.map((b) => {
      const teamId = b.darkHorseTeamId;
      let round: DarkHorseRound = "GROUP_EXIT";
      // Did the team appear in any KO match? If so, they qualified.
      if (finishedTeamIds.has(teamId)) round = "R32";
      if (advancedByRound.R32.has(teamId)) round = "R16";
      if (advancedByRound.R16.has(teamId)) round = "QF";
      if (advancedByRound.QF.has(teamId)) round = "SF";
      if (advancedByRound.SF.has(teamId)) round = "FINAL";
      if (championId === teamId) round = "WINNER";

      return prisma.bonusPrediction.update({
        where: { id: b.id },
        data: { darkHorsePts: darkHorsePoints(round) },
      });
    })
  );
}

// Champion + runner-up: triggered when FINAL is FINISHED
export async function recalcChampionAndRunnerUp(prisma: PrismaClient): Promise<void> {
  const final = await prisma.match.findFirst({ where: { round: "FINAL", status: MatchStatus.FINISHED } });
  if (!final || final.homeScore === null) return;

  const winnerId =
    final.wentToPens
      ? final.homeScore! > final.awayScore! ? final.homeTeamId : final.awayTeamId
      : final.homeScore! > final.awayScore! ? final.homeTeamId : final.awayTeamId;
  const runnerUpId = winnerId === final.homeTeamId ? final.awayTeamId : final.homeTeamId;
  if (!winnerId || !runnerUpId) return;

  const bonusPreds = await prisma.bonusPrediction.findMany();
  await prisma.$transaction(
    bonusPreds.map((b) =>
      prisma.bonusPrediction.update({
        where: { id: b.id },
        data: {
          championPts: b.championTeamId === winnerId ? 20 : 0,
          runnerUpPts: b.runnerUpTeamId === runnerUpId ? 10 : 0,
        },
      })
    )
  );
}

// Master orchestrator: call after any result change
export async function calculateAndStorePoints(prisma: PrismaClient, matchId: number): Promise<void> {
  await recalcPointsForMatch(prisma, matchId);

  const match = await prisma.match.findUnique({ where: { id: matchId } });
  if (!match) return;

  if (match.groupId && GROUP_ROUNDS.includes(match.round)) {
    await recalcGroupStandings(prisma, match.groupId);
  }
  if (["R32", "R16", "QF", "SF", "FINAL"].includes(match.round)) {
    await recalcDarkHorse(prisma);
  }
  if (match.round === "FINAL") {
    await recalcChampionAndRunnerUp(prisma);
  }
}
```

```ts
import { NextResponse } from "next/server";
import { prisma } from "@/lib/prisma";
import { fetchWorldCupMatches, FdMatch } from "@/lib/football-api";
import { calculateAndStorePoints } from "@/lib/recalc";

export async function POST(req: Request) {
  // Authenticate via shared secret
  const authHeader = req.headers.get("authorization");
  if (authHeader !== `Bearer ${process.env.CRON_SECRET}`) {
    return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
  }

  let fdMatches: FdMatch[];
  try {
    fdMatches = await fetchWorldCupMatches();
  } catch (err) {
    return NextResponse.json({ error: String(err) }, { status: 500 });
  }

  const updated: number[] = [];

  for (const fd of fdMatches) {
    if (fd.status !== "FINISHED") continue;
    if (fd.score.fullTime.home === null || fd.score.fullTime.away === null) continue;

    // Find our match by externalId
    let match = await prisma.match.findUnique({ where: { externalId: fd.id.toString() } });

    // If not yet mapped, try to map by team TLA + kickoff date (group stage only)
    if (!match) {
      const home = await prisma.team.findUnique({ where: { fifaCode: fd.homeTeam.tla } });
      const away = await prisma.team.findUnique({ where: { fifaCode: fd.awayTeam.tla } });
      if (home && away) {
        match = await prisma.match.findFirst({
          where: {
            homeTeamId: home.id,
            awayTeamId: away.id,
            externalId: null,
          },
        });
        if (match) {
          await prisma.match.update({
            where: { id: match.id },
            data: { externalId: fd.id.toString() },
          });
        }
      }
    }

    if (!match) continue;
    if (match.status === "FINISHED" && match.homeScore === fd.score.fullTime.home && match.awayScore === fd.score.fullTime.away) continue;

    const wentToEt = fd.score.duration === "EXTRA_TIME" || fd.score.duration === "PENALTY_SHOOTOUT";
    const wentToPens = fd.score.duration === "PENALTY_SHOOTOUT";

    await prisma.match.update({
      where: { id: match.id },
      data: {
        homeScore: fd.score.fullTime.home,
        awayScore: fd.score.fullTime.away,
        wentToEt,
        wentToPens,
        status: "FINISHED",
      },
    });

    await calculateAndStorePoints(prisma, match.id);
    updated.push(match.id);
  }

  return NextResponse.json({ ok: true, updatedMatches: updated });
}
```

```ts
import { PrismaClient } from "@prisma/client";

export type LeaderboardRow = {
  userId: number;
  username: string;
  groupMatchPts: number;
  groupStandingPts: number;
  knockoutPts: number;
  bonusPts: number;
  total: number;
};

export async function getLeaderboard(prisma: PrismaClient): Promise<LeaderboardRow[]> {
  const users = await prisma.user.findMany({
    select: {
      id: true,
      username: true,
      matchPredictions: {
        select: { pointsAwarded: true, match: { select: { round: true } } },
      },
      groupStandingPredictions: { select: { pointsAwarded: true } },
      bonusPrediction: {
        select: { championPts: true, runnerUpPts: true, topScorerPts: true, darkHorsePts: true },
      },
    },
  });

  const GROUP_ROUNDS = new Set(["GROUP_1", "GROUP_2", "GROUP_3"]);

  return users
    .map((u) => {
      const groupMatchPts = u.matchPredictions
        .filter((mp) => GROUP_ROUNDS.has(mp.match.round))
        .reduce((sum, mp) => sum + (mp.pointsAwarded ?? 0), 0);
      const knockoutPts = u.matchPredictions
        .filter((mp) => !GROUP_ROUNDS.has(mp.match.round))
        .reduce((sum, mp) => sum + (mp.pointsAwarded ?? 0), 0);
      const groupStandingPts = u.groupStandingPredictions.reduce(
        (sum, p) => sum + (p.pointsAwarded ?? 0),
        0
      );
      const b = u.bonusPrediction;
      const bonusPts = (b?.championPts ?? 0) + (b?.runnerUpPts ?? 0) + (b?.topScorerPts ?? 0) + (b?.darkHorsePts ?? 0);

      return {
        userId: u.id,
        username: u.username,
        groupMatchPts,
        groupStandingPts,
        knockoutPts,
        bonusPts,
        total: groupMatchPts + groupStandingPts + knockoutPts + bonusPts,
      };
    })
    .sort((a, b) => b.total - a.total);
}
```

### Open Concerns

1. **Penalty winner encoding**: in `recalcDarkHorse` and `recalcChampionAndRunnerUp`, when a knockout match goes to pens, the winner is determined by comparing `homeScore` vs `awayScore` — but our convention is to store the **90-min** score, which would be a draw in pen-deciding matches. This means we'd lose information about who actually won the pens. **Fix needed**: when admin enters a knockout result that went to pens, they must indicate the winner separately, OR we extend the schema to store the penalty score. For an MVP, the simplest fix is: admin enters home/away score as the final score *including* pen result (so 1-1 + home wins pens is entered as 2-1). Document this in the admin UI as a TODO note for the user to consider.

2. **football-data.org match-to-DB mapping**: the sync endpoint maps matches by FIFA TLA codes. The TLAs in the seed data must match what football-data.org returns. If mismatches occur, admin will need to manually link `externalId` via Studio. Acceptable for MVP.

These are noted but don't block plan execution — they're minor implementation details the executing engineer can address during Task 16 (or later).
