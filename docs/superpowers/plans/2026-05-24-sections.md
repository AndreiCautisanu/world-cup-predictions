- `MatchCard` component (handles both group + knockout, placeholder team slots).
- Replace `/pronosticuri` stub with the matchday-tabbed predictions page.

**Deliverable:** can save and re-edit predictions per match; locked matches show the lock badge and disable inputs; placeholder KO slots render "Echipe necunoscute".
