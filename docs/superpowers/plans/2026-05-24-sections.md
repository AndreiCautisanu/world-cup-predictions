## Environment notes (apply to every section)

- Existing repo: Next.js 16.2.6 + React 19.2.6 + Tailwind v4 + TypeScript 6.0.3 + Node 20 (pinned via `.node-version`). Tailwind v4 uses `@import "tailwindcss"` and the `@theme` block — the plan's v3 `@tailwind base; ...` syntax does not work.
- AGENTS.md mandate: consult `node_modules/next/dist/docs/` before writing Next-specific code (this is not Next 15).
- **Prisma 7** with the legacy `prisma-client-js` generator. The datasource `url` lives in `prisma.config.ts`, not `schema.prisma`.
- No local Postgres: use `npx prisma migrate diff --from-empty --to-schema prisma/schema.prisma --script --output …` to emit migration SQL without a live DB; commit it under `prisma/migrations/<n>_<name>/`. The `0_init` migration is already committed AND already applied to the Railway Postgres.
- **Build vs start split:** `package.json` build is `prisma generate && next build` (no DB needed at compile time). Start is `prisma migrate deploy && next start -p $PORT` so migrations apply at container boot when Railway has injected env vars. Do NOT put `prisma migrate deploy` back in build — it was there originally and broke the Railway deploy because `DATABASE_URL` isn't available during build.
- **Railway deploy is live** at https://cupamondiala.andrei42.com. Two services in the `appealing-creativity` project: `main-node` (Next.js) and `Postgres`. `main-node` has a `DATABASE_URL=${{Postgres.DATABASE_URL}}` reference variable; that pattern is required for any future env var that needs a cross-service value. Healthcheck is on `/`, so `/` must always return 2xx — keep that in mind if you swap pages.
- **Jest config file is `jest.config.cjs`** (not `.js`). The eslint config has a `*.cjs` override that allows `require()` since next/jest is CJS-only.
- The original InRing teaser at `app/page.tsx` is gone. Currently `app/page.tsx` is a Section-1 placeholder that renders "Cupa Mondiala 2026 — în pregătire" purely to keep the Railway healthcheck green.
- Work on the `master` branch unless told otherwise. Direct push to master is allowed (`.claude/settings.json`).
- Git committer identity is `Andrei Cautisanu <andrei.cautisanu@gmail.com>` — configured locally for this repo only.

## Section 5 — Scoring Orchestrator + Admin (Tasks 14–17) ✅ DONE

Shipped to production on 2026-05-26, commits `3dbf3be..75b0518` on `master`.

**What landed:**
- `lib/recalc.ts` — `computePointsForPrediction` (pure dispatch helper, 8 tests covering group/KO/THIRD_PLACE/regulation/ET) + `recalcPointsForMatch`, `recalcGroupStandings`, `recalcDarkHorse`, `recalcChampionAndRunnerUp`, and the `calculateAndStorePoints` master orchestrator. Group standings sort by pts → gd → gf → team id (stable fallback); dark horse uses played-in-round + advanced-from-round sets so a team that lost their R32 lands on `R32` (not `GROUP_EXIT`). Convention: the 90-min `homeScore`/`awayScore` columns encode the eventual winner even when `wentToPens = true` — admin enters the side-that-advances score as the higher value.
- `/admin/*` shell — rose-accented `app/admin/layout.tsx` does the server-side admin gate via `auth()` and redirects non-admins to `/clasament`. `app/admin/page.tsx` redirects to `/admin/rezultate`. Header reuses the display-font wordmark with a rose tint to signal "this is the admin world."
- `/admin/rezultate` + `app/admin/rezultate/AdminResultRow.tsx` (client) — scroll-snap round tab strip (GROUP_1…FINAL incl. THIRD_PLACE), one card per match. Group matches inline scoring inputs (+ flag/name); KO matches add Prelungiri / Penalty-uri toggles and surface the pen-winner convention copy. Empty KO slots render a team picker. Save button posts to `/api/admin/results`, then `router.refresh()` re-renders the page so the FINISHED badge appears.
- `POST /api/admin/results` — zod-validated, admin-gated; updates the match row + calls `calculateAndStorePoints(prisma, matchId)` so all four scoring chains run before the response.
- `POST /api/admin/sync-results` — cron-secret authenticated (`Authorization: Bearer $CRON_SECRET`). Pulls all WC matches from [lib/football-api.ts](lib/football-api.ts), filters to FINISHED, maps by `externalId` (with a TLA-pair fallback for any group-stage match the bootstrap didn't externalId-link), back-fills KO `homeTeamId`/`awayTeamId` from FD's TLA when our DB still has them null, and triggers `calculateAndStorePoints` per updated match. Returns `{ ok, updatedMatches, linkedExternalIds, skipped }`.
- `/admin/utilizatori` + `AdminUserRow` (client) — admins-first sort, per-row toggle admin + reset password (min 8 chars). `POST /api/admin/users` enforces a last-admin guard so the sole admin can't accidentally demote themselves.
- `/admin/cod-invitatie` + `CodInvitatieForm` (client) — shows active code in big display type with rose gradient, toggle / rotate actions, code history list. `POST /api/admin/invite-code` runs rotate as a single transaction (deactivate-all + create-new) and catches `P2002` (unique violation) as 409.
